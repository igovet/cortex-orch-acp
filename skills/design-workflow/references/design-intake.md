# Design intake question bank

Read project evidence and retained answers first; select only material gaps.
Group at most five questions per round, normally one round and at most two.
Offer project-grounded choices, explain differences and preserve custom text.

- Product: What is being designed and which primary job should it improve?
  Is this a new product, a redesign or refinement of the existing direction?
- Audience: Who uses it, in what context, with which accessibility/language needs?
- Platforms: Responsive web, native mobile or both? Which devices and size classes?
- Screens and content: Which screens, priorities, actual copy/assets and journeys?
  Which loading/empty/error/permission states? Which features are explicitly excluded?
- Direction: Preserve the existing identity, evolve it, or explore a new direction?
  Which typography, density, tone and brand constraints are non-negotiable?
- References: Which supplied examples are useful and why? If none, is bounded
  research authorized? Availability of URLs is not evidence the pages were viewed.
- Avoid: What existing traits must not recur? Are there prohibited visual patterns?
- Constraints and risks: Which stack, components, performance, licensing, privacy,
  asset budget and interaction/accessibility requirements matter?
- Acceptance and verification: What observable criteria, viewports, states,
  screenshots and independent reviews demonstrate success?

Record answers in plan objectives and assign a writer to durable product/design
documents before dependent design work. Delegate only explicitly granted creative
choices; never manufacture product features from an aesthetic reference.
