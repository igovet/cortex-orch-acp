# Worker tool discipline

Declared scope coordinates parallel writers; it is not a project write boundary.
Before changing additional project paths, reserve them through `access_request`.
Private storage and user-protected paths remain unavailable. Outside-project
work uses the advertised permission route and follows the user's current mode.
A denied action is final; never substitute a native tool, copy or temporary file.
Use scope or replan requests only when the plan itself must change.

Run reportable checks through Cortex MCP `command_run` or its approved outside
route and retain terminal receipts for the structured result. Native workspace
aids, where permitted, do not produce Cortex command evidence. Writing workers
verify edits; read-only workers run only authorized non-mutating checks.
