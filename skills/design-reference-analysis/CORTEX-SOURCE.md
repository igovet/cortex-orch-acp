# Source and provenance

This Cortex skill is Cortex-authored. It contains no text, markup, assets,
values or files copied from any upstream project, and it has no LICENSE file
because nothing is vendored.

The method was informed by an upstream design-reference skill, `taste-skill`
(https://github.com/senlindesign/taste-skill, repository HEAD
`6dce223f2f5665d3636ca9a44ec3a7aa1322a9b8` at the 2026-10-14 audit). The audit
could not establish a license for it: the repository has no LICENSE file and the
license API returned no license. Its README was not read as raw text, so any
license claim there is unverified. For that reason no upstream file was vendored.

What was taken from the upstream description, as recorded by the 2026-10-14
upstream audit: the idea of analyzing a reference interface's typography,
spacing, color and composition, explaining why it works, and applying principles
rather than copying the interface.

What is Cortex-specific:

- The four-step method (measure, find patterns, state principles with
  trade-offs, transfer), the output table, and the anti-copy guards.
- Rules for estimated versus measured values, for URLs that cannot be observed,
  and for where the analysis is saved (a writing role, not a read-only role).

If the upstream later publishes a license grant, a separate decision is needed
before any of its text is considered for vendoring.
