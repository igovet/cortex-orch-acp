# Report publication

Publish a complete immutable report and submit the structured result through
Cortex MCP. Use either the inline report route or an owned draft followed by
publication, as the live tool descriptions specify. Retain exact acknowledged
references; never rewrite published results. Follow the operation's advertised
retry and serialization guidance for uncertain delivery or malformed input.

Report work performed, findings, changes, actual checks, contradictions, limits,
risks and next action. Every unrun or unverified check needs a concrete blocker;
prose cannot manufacture evidence. A conclusion or verdict alone is not a report.
The runtime owns review, verification and completion. A final chat message
does not replace the structured result.
