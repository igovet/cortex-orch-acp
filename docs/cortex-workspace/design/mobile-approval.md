# Mobile approval: Gate M

**Status: partly recorded. The owner approved the static phone mockups and the decisions below on 2026-11-17. Physical-device and accessibility observations are not recorded, so nothing here qualifies Android for release.**

**Recorded owner decision, 2026-11-17.**

- Approved: the static mockups `prototypes/cortex-workspace/mobile/index.html` and `mobile.css` as the design basis for the phone.
- Decided with that approval: the Android client is the same adaptive interface as the desktop (not a separate React Native application, and not two competing navigation concepts); Android connects only to remote machines; no tab strip on the phone; larger touch controls on the phone only; the first version has read-only Code and no terminal; app lock is an optional setting, off by default.
- Gate D was already approved on 2026-11-05 ([desktop approval](desktop-approval.md)).

**Not recorded:** physical-device observations (install, launch, camera, touch, keyboard, Back, lifecycle, network changes), accessibility observations (large text, screen reader, touch target measurement), screenshots of the built phone shell, and any unresolved risk list beyond [risks and open decisions](../risks-and-open-decisions.md). This approval covers static mockups and the listed decisions only. It does not approve the built app, push, or a release, and revisions are not approval.
