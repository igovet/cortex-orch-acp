# Push notifications

**Status: planned; no implementation or qualification is implied.**

Decision: Plan FCM with metadata-only notifications sent through a self-hosted push gateway container on the owner's server ([ADR 0011](0011-self-hosted-relay-and-push-gateway.md)); the client fetches authorized contents over the secure channel. The gateway's caller authentication is an open owner decision ([CW-P01](../backlog/CW-P01.md)). Delivery and no-GMS availability remain limited and must be displayed honestly.

Consequences: implementation and qualification are pending; revisit if feasibility or security validation fails.
