# CW-S04: Python draft and execution identity with authoritative read projections

**Status:** built; no-paid checks pass · **Phase:** 3+ · **Size:** L

## Goal

Add the project-scoped Workspace adapter in the Python runtime: a description-only draft that makes no model or runtime call, explicit activation of Cortex for a project, stable public task and execution identities bound to the runtime task and ACP session, and typed read projections with explicit unknown states. The adapter is the only component that translates private runtime tables into public records.

## Requirements

CW-R04 (versioned, server-authorized commands), CW-R15 (Cortex-specific views need explicit activation and the public adapter) and CW-R24 (description-first creation; a title is generated or edited, never required). See [requirements](../requirements.md).

## Inputs

- [domain-model](../domain-model.md) and [protocol](../protocol.md): distinct task, execution, decision and result identities.
- [ADR 0001](../adr/0001-product-task-and-execution.md) and [ADR 0014](../adr/0014-local-service-transport.md).
- The existing bootstrap deduplication of stable source identities, and the runtime state vocabularies in `src/cortex_runtime/orchestration/state.py` and `src/cortex_runtime/delegation/events_store.py`.

## Deliverables

- `src/cortex_runtime/workspace_api/`: storage, projection queries and the request handler.
- Additive project-local tables registered through the normal initializing store open. Inspection opens (`initialize=False`) create nothing.
- Mapping version 1 from runtime lifecycle to public phase and execution state, following the table in [protocol](../protocol.md). Missing, unrecognized or contradictory facts map to `unknown` with a warning.
- The `_cortex/workspace` extension dispatch on the existing Agent. It stays unadvertised until its storage requirements and tests pass.

## Acceptance

Positive:

- Creating a draft makes zero runtime, engine or model calls.
- Activation is a separate, recorded action with actor and time.
- Every lifecycle state in the mapping table maps exactly as specified.

Negative:

- A generic ACP session identifier is never returned as a task identifier.
- Prompt `_meta` is not used as identity.
- No title input is required, and no title is generated by this item.
- Missing or contradictory evidence stays `unknown`; it never becomes a pass.
