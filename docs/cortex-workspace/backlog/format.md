# Backlog format

Each entry's status is stated on its page and in the [index](index.md): implemented, partly implemented, not implemented or not confirmed in code. Size is effort: S ≤ half a day, M about one day, L at most two days. Split any item that exceeds L before implementation. Each entry names goal, requirements, inputs, deliverables, positive and negative acceptance, dependencies, validation and documentation impact. Actual check results are recorded only after execution. Gate D and Gate M are owner decisions, not automatic milestones.
