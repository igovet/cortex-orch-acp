# Implementation backlog

> Source and test references in these items that name modules, scripts and tests of the former Python runtime (removed on 2026-11-16) appear as "the former ..." and are history. Commands in acceptance sections that name removed Python tools are not current commands: use `scripts/cortex-xtask.sh` and `scripts/cortex-paseo-tools.sh` equivalents (see the verification page).

The Status column states what the code in the repository implements, in these terms:

- **Implemented**: the behavior exists in source and is covered by no-paid automated checks (fake engines, containers, text-only rendered audits). This is not release qualification.
- **Partly implemented**: the page names what exists and what is missing.
- **Not implemented**: no code exists for the item.
- **Not confirmed in code**: the item could not be found in source; it is not claimed as done.
- **Built (CW-S items) and Mock built (CW-D items)**: the local slice items and the prototype items keep their own records.

Not verified live for any item: paid model runs, a real Ubuntu desktop session and GPU, a real microphone, and a published GitHub release. See [testing and acceptance](../testing-and-acceptance.md) and [platforms](../platforms.md).

Gate D passed on 2026-11-05: the owner accepted the clickable browser prototype, whose phases P0 to P6 are mock-only, unqualified code. CW-D05 is closed; CW-D08 is not built. Existing first-round mocks are historical. Mobile is deferred by the owner decision of 2026-11-05: CW-M03 (Gate M) gates only the Android and phone-only items and the items that depend on them, and desktop items do not depend on it. The local desktop slice (CW-S01 to CW-S12) was the first implementation, and the desktop screens and features in the table run on real data on top of it. The remaining milestones follow the [roadmap](../roadmap.md). P05 is post-v1. See [format](format.md) and [roadmap](../roadmap.md).
